# Windows Intelligence 0.2.42

## 用户可见的执行过程

用户要求操作电脑时，回复面板默认显示“执行过程”。每步包含简短操作说明、实际 PowerShell 命令、实时标准输出、错误输出、运行时间和退出码。下一步分析和最终回复与执行记录同时显示，成功、失败和超时使用不同状态。关闭/ESC 沿用取消机制，取消仍会终止运行中的命令进程树。

操作说明由模型通过可选 description 字段提供；没有说明时显示“执行 PowerShell 命令”。状态与结果来自实际执行器，不把模型的计划当作完成结果，也不显示服务商内部 reasoning_content。回复文字不再等待朗读音频缓冲才出现。记录在回复完成后保留，打开新会话或重试时重新开始。

记录仅在当前会话内存中保存，每个任务最多八步，每步 stdout/stderr 保留约 6000 字符；超过限制有截断标记。已知当前模型密钥与常见凭据赋值形式在展示时隐藏。命令和原始结果仍按原有工具协议执行、返回模型；界面不额外保存本机执行日志、不把记录混入会话历史。读取输出和界面更新分别限量，更新计时器仅在命令运行时启动。

沿用原有输入胶囊、配色、快捷键、静默/朗读、截图、取消、模型配置和工具权限。执行区可折叠、滚动、选中复制，整体高度受当前屏幕工作区限制。

## 音箱方案调整

本版本不刷写 OH2P、不开放 SSH、不停用原生小爱。后续优先采用小爱官方技能上下文方式，详细边界和接入材料见 [无需刷机的接入方案](XIAOAI_OFFICIAL_SKILL.md)。这不是已经连通音箱的发布说明。

## 验证与产物

新增执行过程测试覆盖真实 PowerShell 实时输出、退出码/错误、取消、已知密钥分块脱敏，以及实际 WPF 命令和结果展示；原有多步文件操作与失败恢复测试继续运行。版本构建、回归、签名、安装结果以 `artifacts/update-0.2.42/` 报告为准，不把本机测试当作其他设备或 OH2P 的验收。

本次实际结果：Release 构建 0 警告、0 错误；完整回归 20 项通过、0 失败。当前用户配置的真实 AI 服务也通过只读 PowerShell 往返测试。0.2.42.0 使用原有 CN=JINZAIXI 签名安装到原包族，安装后的托管/原生 DLL 哈希与打包载荷一致；设置、历史哈希不变，没有修改证书存储。安装后设置、文字输入、ESC、单实例和 Copilot provider 注册测试通过，物理硬件键本身未作为脚本测试结果。

安装版在静默输入窗口测试结束后的五次空闲采样约 442.4 MiB 工作集（约 464 MB），未强制缩减工作集。独立语音测试进程在加载 ASR/TTS 后约 1958 MiB，空闲释放后约 311 MiB，重新加载识别结果一致；后者不是完整桌面程序占用，不能承诺重模型运行时也低于 500 MB。

完整安装 ZIP 包含签名 MSIX、公开证书、安装脚本、说明和 SHA-256 清单；不包含用户配置、API Key、签名私钥或音箱固件。本轮未向 GitHub 发布。OH2P 官方技能尚未建立连接或通过真机验收。
