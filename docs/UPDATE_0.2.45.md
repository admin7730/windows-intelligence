# Windows Intelligence 0.2.45

设置窗口重写为 macOS 风格的浅色玻璃界面：系统 Mica 背景、半透明侧栏、彩色图标、红黄绿窗口按钮、圆角内容分组和悬浮保存栏。增加设置搜索，重做输入框、密码框、选择菜单、开关和细滚动条。保留现有全部配置、快捷键、语音、截图和电脑操作功能。

已完成 21 项既有回归以及设置搜索、窗口控制、820 × 560 布局和减少动画专项检查。已安装本机 0.2.45.0，本机升级保留设置与对话历史。完整签名安装包见 GitHub Releases，原始本机校验记录未提交仓库。

玻璃背景由 Windows DWM 合成，未开启整窗 AllowsTransparency 或持续截图模糊。背景不可用时保留浅色回退，高对比度使用系统颜色；开关与页面过渡遵循“减少动画”和 Windows 动画设置，空闲没有新增持续动画。

新增官方小爱技能接入代码和 QQ 检测页，复用现有电脑 AI 与工具，保留原来的快捷键、截图、首段语音放行与结论前置。所有新接入默认关闭，不额外监听电脑控制端口，不刷写音箱。

技能桥接服务遵循小米公开签名示例，验证签名、正文、时间、技能和配对用户/设备。任务持久化且只领取一次，重启或断网不自动重做。结果通过官方 to_speak 返回；较慢任务先如实说明处理中，后续可查询结果，不假装已完成或宣称支持未经验证的后台推送。

Windows 新入口通过主动 HTTPS 请求取任务，用当前模型和 PowerShell 权限在原有可见界面执行。QQ 文件变化只记录所选目录的稳定可读元数据；消息入口仅为用户授权的 Windows QQ 通知，不覆盖全部聊天历史，不读取加密聊天数据库、不自动执行 QQ 内容。音箱读取 QQ 数据另有本地开关。

服务代码在 `src/XiaoAI.SkillRelay/`，共用协议在 `src/XiaoAI.Protocol/`，材料和具体边界见 [接入说明](../integrations/xiaoai/README.md)。当前缺真实平台配置和 HTTPS 部署，尚未完成小米或 QQ 账号联调。本机测试不代表音箱已接通或全部 QQ 消息可读。
