# Windows Intelligence 0.2.48

按平时使用的 Copilot 键或自定义唤醒键，直接说：

- 你去给 DeepSeek 说一声，让它检查项目里的测试。
- 请把整理这份项目文档的任务发给 Codex。
- Please ask Codex to list the tests.

助手弹出派发选择器并显示它听到的任务。按项目筛选或搜索对话标题和目录，选好后点击“发送任务”。选择已有对话会沿用其原生会话和工作目录。想开独立对话时，先选项目，再选列表中的“新建对话”。需要新项目时，输入名称即可，发送时会在“文档 / Windows Intelligence Projects”下创建目录。

DeepSeek 指本机安装的 DeepSeek Harness。选择器读取 Harness 的本机工作区索引和会话摘要。GPT、ChatGPT 或 Codex 使用 Codex 本机执行入口和原生会话协议，项目按会话工作目录归类。选择器显示这些入口能访问的本机会话，Codex 的普通列表不含已归档对话。普通 ChatGPT 网页和 DeepSeek 网页的聊天不在本机列表范围内。

确认前不会派发任务。任务完成后，原助手会显示结果。关闭助手后，已排队的任务继续运行，可从托盘查看。原工具仍需自己的登录或凭据。只读选项和电脑自动操作设置继续生效。

验证覆盖已转写语音打开弹窗、读取分批返回的原生列表、搜索、确认和匹配会话 ID。另在两个真实工具上分别创建只读测试对话，验证该对话能被列出并收到发送到同一原生 ID 的后续任务。
