# Windows Intelligence 0.2.46

对话按段保存。每次启动先开新对话，距上次交互不足默认 15 分钟时继续同一段，超时自动新建；时间窗口可在“对话与记忆”调整。输入框、托盘和设置都有新对话及历史入口。历史窗口可搜索、阅读、继续或删除一段。新对话只携带自身上下文，不混入其他对话。旧 history.json 只读迁移为“以前的对话”，原文件保留；完成真实新一轮后才保存新格式，不持久化图片。

最多保留 300 段，每段 100 轮，模型请求仍只带当前段最近 8 轮。关闭本机历史保存时不读取或新写磁盘历史；从启用改为关闭会按原设置行为清除本机历史。个人记忆由用户编辑，会随问题发送给当前模型，不自动从对话中推断永久记忆。

指令记忆支持启停、修改触发词、添加和删除规则、选择账户查询或自定义助手任务。完整匹配，忽略空格、标点和大小写，并兼容繁简中文；不使用包含匹配，避免“不要查询”等表达误触发。自定义任务仍使用既有模型、工具与权限。

内置 DeepSeek 查询走官方 GET /user/balance，使用已配置官方账户凭据，直接格式化真实余额，不让模型猜测。余额接口不含历史 Token 用量和消费账单，回复提供官方用量页面。MiniMax 语音按量账户尚无本项目验证的公开余额接口，只提供官方控制台路径并明确说明无法仅凭语音 Key 返回现金余额。国际站 Token Plan 支持官方套餐额度查询，需单独保存订阅 Key，不把语音 Key 发到套餐接口，不把套餐额度当作现金余额。

新增简体中文、繁體中文与 English。总览里切换并保存，设置、历史入口、输入框和常用状态本地化；托盘随切换更新。回复提示词跟随所选语言，用户本次明确指定其他语言时优先遵循。保留原始提问、转写、历史正文、命令、输出和用户自填设置；不对这些内容强制转换繁简或翻译。Qwen3-ASR 继续处理粤语、普通话、英文和中英混说，MiniMax 朗读保持自动语言识别。

验证覆盖会话隔离、15 分钟边界、手动新建和历史续聊、重启、旧记录保留、不持久化图片、关闭保存、规则误触发和凭据隔离；三语言页面有渲染检查。DeepSeek 使用现有凭据的真实官方余额请求已通过，测试不输出金额或密钥。MiniMax 国际站套餐使用模拟响应测试，真实订阅账户和语音按量余额未联调。
