# 性能

## 当前边缘渲染

GPU 读回使用两组 staging 纹理和非阻塞 Map，只处理彩色屏幕边缘。屏幕中心保持透明，不再创建独立背景合成材质。12 ms 的 UI 调度器只在边缘动画活动时运行，实际呈现速率受当前 Windows 会话和合成节奏约束。

使用 WPF DispatcherTimer 与高精度单调定时更新 HLSL 时间常量，保留边缘呼吸、固定色相和彩色截图脉冲。D3D11 在 GPU 上运行边缘着色器，以预乘 Alpha 分层窗口呈现，包含 GPU 纹理回读和 CPU 拷贝。空闲叠加层停止连续绘制与回读。

测试速率是进程实际接受的分层窗口更新速率，显示终端刷新率由系统配置给出。多显示器与 1440p / 4K、其他 DPI 和刷新率的验收见测试报告。
