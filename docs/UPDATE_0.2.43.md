# Windows Intelligence 0.2.43

开启自动朗读时，操作说明、命令和执行进度继续显示；最终答复、标准输出、错误输出、退出码和具体完成状态暂存，等待第一段可播放语音生成后就展示，并开始播放。后续片段同时继续生成，不等待整段完成，也不要求先缓冲四秒或等待固定十四秒。不显示首段语音到达前的答复草稿。

生成期间显示“正在生成首段语音 · 就绪后显示结果”。MiniMax 的 HD/Turbo 回退和其他已有 TTS 路径沿用原逻辑。若没有任何可用语音，明确提示失败并显示文字结果；ESC 取消会停止等待，迟到的语音不得重新打开结果或播放。静默模式、关闭自动朗读或禁用 TTS 时不等待语音，保留实时文字和操作输出。

首段就绪信号在解码后的音频进入可播放队列时触发，不以 HTTP/TLS 连接建立或收到响应头作为依据。后续继续复用已有语音队列和超过 4 MiB 后的 PCM 临时文件缓冲机制，不把长回复无限留在内存。工具执行结果仍立即返回模型用于后续操作，展示等待不会阻塞电脑操作本身。

新增时序测试使用可控的合成器和播放适配器验证：首段尚未生成时不能泄露结果；仅有 0.1 秒首段、末段仍在等待时就放行结果与播放；后续音频继续生成和播放；生成失败可回退文字；ESC 后不显示或播放迟到结果。测试不要求实际扬声器播放，也不把模拟 TTS 当作 MiniMax 服务实测。

构建、安装、签名和测试证据保存在 `artifacts/update-0.2.43/`。音箱接入和固件状态不受本次展示时序调整影响。

实际验证：Release 构建 0 警告、0 错误；修正后的完整回归 21 项通过、0 失败。当前配置的 MiniMax 端点实际返回并成功解码 1.22 秒语音。可控时序测试通过首段前隐藏结果、0.1 秒首段即放行且后续仍在生成、失败回退和 ESC 取消。
